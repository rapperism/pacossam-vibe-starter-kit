# 내 구독료 계산기 — 스타터킷 예제 앱

『빠코쌤 바이브코딩 7일 스타터킷』 1장 7일 로드맵을 그대로 따라 만들면 이 화면이 나옵니다.
로그인도, 서버도, 데이터베이스도 없습니다. **파일 3개와 브라우저 하나**면 끝납니다.

- **바로 열어보기(라이브 데모):** https://rapperism.github.io/pacossam-vibe-starter-kit/
- **이 저장소:** https://github.com/rapperism/pacossam-vibe-starter-kit — 따라 만들기용 읽기 전용 공개 예제입니다. 내려받아 내 저장소로 복사해 고쳐 쓰세요.

```
.
├── index.html   화면 뼈대 (목록 화면 + 입력 화면 + 관리 창)
├── style.css    디자인 (색 3개, 글자 3단, 8px 여백 규칙)
├── app.js       기능 (추가·수정·삭제·합계·저장·내보내기)
└── README.md    이 문서
```

## 1. 실행하는 법 (설치 없음)

**가장 빠른 길:** 위 라이브 데모 주소를 브라우저에서 엽니다. 설치도, 내려받기도 필요 없습니다.

**내 컴퓨터에서 열기**

1. 이 저장소에서 초록색 `Code` 버튼 → `Download ZIP`을 눌러 압축을 풉니다. (git을 쓴다면 `git clone https://github.com/rapperism/pacossam-vibe-starter-kit.git`)
2. `index.html` 파일을 더블클릭합니다. 브라우저에서 바로 열립니다.
3. 처음에는 화면이 비어 있습니다. **관리 → 샘플**을 누르면 예시 구독 6개가 채워집니다.

> `file://`로 열어도 모든 기능이 동작합니다. localStorage는 같은 파일 경로 기준으로 저장되니, 파일을 옮기면 목록이 비어 보일 수 있습니다. 그때는 관리 → **내보내기**로 백업한 JSON을 옮긴 뒤 **가져오기**로 되살리세요.

## 2. 무엇이 되나

| 기능 | 설명 |
| --- | --- |
| 구독 추가 | 서비스명, 금액, 결제 주기(매달/매년), 카테고리, 결제일 |
| 수정·삭제 | 목록의 `수정` / `삭제`(두 번 눌러 확인) |
| 한 달 합계 | 매년 결제 항목은 12로 나눠 월 환산으로 더합니다 |
| 1년 예상 지출 | 한 달 합계 × 12 |
| 가장 비싼 구독 | 월 환산 금액 1위 |
| 이번 달 남은 결제 | 오늘 이후 결제일이 남은 매달 구독의 합 |
| 카테고리 비중 | 카테고리별 금액과 비율 막대 |
| 필터·정렬 | 카테고리 칩, 결제일 순 / 금액 순 / 이름 순 |
| 자동 저장 | 브라우저 localStorage. 새로고침해도 그대로 |
| 백업 | JSON 내보내기 / 가져오기 |
| 입력 검사 | 빈 이름·글자 금액·1~31 밖 결제일을 화면 안에서 막습니다 |

## 3. 7일 로드맵과 이 코드의 대응

| Day | 하는 일 | 이 앱에서 확인할 곳 |
| --- | --- | --- |
| 1 | 아이디어 자르기, 첫 화면 | `index.html`의 `.summary` — 한 달 합계가 가장 크게 |
| 2 | 화면 2개와 이동 | `#view-list` ↔ `#view-form` 전환 (`showList`, `openForm`) |
| 3 | 저장(localStorage) | `load()`, `save()`, `STORAGE_KEY` |
| 4 | 일부러 에러 만들기, 입력 검사 | `validate()`, `.invalid`, `.error` |
| 5 | 디자인·모바일 | `style.css`의 `:root` 색 3개, `@media (max-width: 480px)` |
| 6 | 배포 | 아래 4번 |
| 7 | 피드백 반영 | 결제일 순 정렬, `이번 달 남은 결제` (`remainingThisMonth`) |

## 4. 무료로 배포하기

**가장 빠른 길 (Vercel)**

1. 이 폴더를 GitHub 저장소로 올립니다(저장소 이름은 영문 소문자).
2. [vercel.com](https://vercel.com) → `Add New → Project` → 저장소 선택 → `Deploy`.
3. 정적 파일이라 빌드 설정 없이 1분 안에 주소가 나옵니다.

**가장 단순한 길 (GitHub Pages)**

1. 저장소 → `Settings → Pages` → Source: `Deploy from a branch` → `main` / `root`.
2. `아이디.github.io/저장소이름` 주소가 생깁니다.
3. 파일이 모두 상대 경로(`style.css`, `app.js`)라서 하위 경로 배포에서도 그대로 동작합니다.

> Vercel 무료 Hobby 플랜은 약관상 **개인·비상업적 용도**입니다. 이 앱으로 돈을 버는 순간 Pro(월 $20)가 필요하고, 그게 아니라면 GitHub Pages가 안전합니다.

## 5. 데이터 구조 (JSON 백업 파일)

```json
{
  "app": "내 구독료 계산기",
  "version": 1,
  "exportedAt": "2026-11-17T01:20:00.000Z",
  "subscriptions": [
    { "id": "s_abc123", "name": "넷플릭스", "amount": 13500, "cycle": "month", "category": "영상", "day": 22 },
    { "id": "s_def456", "name": "노션 플러스", "amount": 96000, "cycle": "year", "category": "AI·생산성", "day": 3 }
  ]
}
```

- `amount`는 **숫자**입니다. 글자로 저장하면 합계가 `1350013500`처럼 이어 붙습니다(4장 에러 10번).
- `cycle`은 `month` 또는 `year`입니다.

## 6. 한계 (정직하게 적어 둡니다)

- 데이터는 **이 브라우저에만** 저장됩니다. 다른 기기·다른 브라우저와 공유되지 않습니다. 라이브 데모에 넣은 구독도 그 브라우저에만 남습니다.
- 브라우저 데이터를 지우거나 시크릿 모드로 열면 저장이 되지 않을 수 있습니다. 중요한 목록은 JSON으로 백업하세요.
- 로그인·결제·알림은 이 예제의 범위 밖입니다. 1장 Day 1에서 "v1에서 빼는 네 가지"로 설명한 부분입니다.

## 7. 직접 고쳐 보기 (연습 문제)

1. 카테고리 칩 옆에 `이번 달 결제 예정만 보기` 토글을 붙여 보세요.
2. 목록 항목에 메모 한 줄을 추가해 보세요(입력 화면 + 저장 구조 + 목록 표시, 세 곳을 고쳐야 합니다).
3. 합계 금액을 눌렀을 때 `연간 예상 지출`이 잠깐 크게 보이게 해 보세요.

AI에게 시킬 때는 2장 프롬프트 **C-1(새 기능 하나 추가)** 형식으로, "다른 건 절대 건드리지 마"를 붙이세요.
